# taste-board

クリニックサイトの**テイスト（好みの方向）を確認するためのアンケートボード**。
打合せで口頭では詰めきれない「印象・配色・書体・ロゴ・医院名の状況」を、
選ぶだけで答えてもらうための1枚もの。

- 公開URL: https://sanc-official.github.io/taste-board/
- 単一HTML・依存ライブラリなし・ビルド不要

## 設計方針

- **回答は端末のブラウザ（localStorage）にのみ保存され、外部へ送信しない。**
  最後に「回答をまとめてコピー」でテキスト化し、本人がチャットへ貼って返す。
- **このリポジトリは公開。** 案件名・院名・所在地・開院時期などの
  個別情報は絶対に書かない。汎用のアンケートとして保つ。
- 参考サイトのリンク先は mikke!（国内Webデザインギャラリー）の紹介ページ。

## 使い回すとき

案件ごとにフォークせず、原則このまま使う。設問を足したい場合は
`index.html` 冒頭の定数（`TARGETS` / `NGCOLORS` / `DIRS` など）と
`LABELS`（コピー用テキストの見出し）を揃えて編集する。
`KEY`（localStorage キー）を変えると過去の入力は引き継がれない。
